# LembrAI — site de apresentação

Página pública do LembrAI, construída com React, TypeScript, Vite e Tailwind CSS.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Publicação

Cada push para `main` executa o workflow em `.github/workflows/deploy-pages.yml` e publica a versão de produção no GitHub Pages.

## Conteúdo

O site apresenta os recursos pessoais implementados ou em curso no LembrAI: agenda, tarefas e consultas, check-ins de humor e energia, insights em texto e sessões de foco. A experiência de vínculo com profissional e compartilhamento por consentimento está identificada como em desenvolvimento e validação.

O site não oferece cadastro, download público, coleta de dados ou atendimento clínico.
